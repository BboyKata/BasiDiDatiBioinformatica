# Appunti Basi Di Dati - Bioinformatica - UNIVR A.A. 2025/2026

Questi sono gli appunti che ho preso per l'esame _"Basi di Dati"_, tenuto dalla Prof.ssa Olliboni, erogato nell'A.A. 2025/2026 all'Università Degli Studi Di Verona. 

**Gli appunti compilati sono disponibili sul file `[main.pdf]([url](https://github.com/BboyKata/BasiDiDatiBioinformatica/blob/main/main.pdf))`**

## 📚 Contenuto del progetto

- File `.tex` che contiene il file sorgente LaTeX degli appunti
- Il PDF `main.pdf` generato corrispondente al `.tex` che contiene i sovracitati appunti.  
- Una cartella `graphics/` con figure, immagini, grafici utilizzati nei documenti.  
- Eventuali file di supporto, bibliografia o altri allegati necessari per la generazione dei PDF.

## 🛠️ Come usare / compilare

Se vuoi ricompilare i sorgenti `.tex`:

```bash
git clone https://github.com/BboyKata/BasiDiDatiBioinformatica.git
cd BasiDiDatiBioinformatica
# supponendo che usi LaTeX (pdflatex / xelatex / lualatex)
pdflatex main.tex   # o il nome del file .tex principale
# ripeti fino a che la compilazione non segnala errori
